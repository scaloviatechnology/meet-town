# Git & GitHub Push Helper

To push your repository to `https://github.com/scaloviatechnology/meet-town`, run these commands in your terminal:

```bash
cd /home/saiful/scalovia/live-meeting
git init
git remote add origin https://github.com/scaloviatechnology/meet-town.git
git checkout -b main
git add .
git commit -m "feat: Meet-Town v1.0.0 - Gather Town style desktop virtual office with security audit"
git push -u origin main
```
